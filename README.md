# Airship Simulation Project

This project simulates the dynamics and control of an airship using various mathematical models and algorithms. It includes modules for modeling, control, observation, and trajectory planning.

## Project Structure


## Features

- **Airship Dynamics**: Implements the equations of motion for the airship, including aerodynamic and buoyancy forces.
- **Control Algorithms**: Includes a fixed-time BLF controller for robust control of the airship.
- **State Estimation**: Observer module for estimating unmeasured states and disturbances.
- **Trajectory Planning**: Tools for generating and following desired trajectories.
- **Simulation Framework**: A modular simulation framework for testing and validating the airship model and control algorithms.
